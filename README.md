# Emilio Daza — Portfolio

Personal portfolio for [emiliodaza.com](https://emiliodaza.com), built with React and Vite and deployed to GitHub Pages on pushes to `main`.

## Local development

```sh
npm ci
npm run dev
```

Run `npm run lint` and `npm run build` before publishing.

The content in `src/App.jsx` follows Emilio's September 2026 résumé. The downloadable résumé is `public/cv.pdf`; replace that file when the source résumé changes. The Izipay results displayed on the site are explicitly labeled as simulator results.
